# One Stop Online Store


## Description of the Project
An online store that lets a shopper browse products, add them to a cart, and check out

## Features

- Shows every product in the store
- Adds products to the cart by id
- Shows cart and total
-  Checks out with payment, change, and receipt

## Setup

### Prerequisites

- Java 17 (Amazon Corretto), the version used in class.
- IntelliJ IDEA Community Edition: <https://www.jetbrains.com/idea/download/>

### Running the application
1. Open the project in IntelliJ
2. Run store.java
